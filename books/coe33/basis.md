# RTA基礎知識・Tips

## 準備編

### キーバインド

[F] キーはテキスト送りに使えますが、同時にマップ中の攻撃にアサインされており、テキスト終了時に連打していると攻撃が誤爆します。

キーマウでプレイしていない限りキーボードで攻撃することはないはずなので、[F] 以外のキーに再割り当てしておきましょう。テキストが [F] で進行できるのは変わらず、誤爆を防げます。

### クロスヘア（照準）が設定から表示できる

設定にある「点の中央表示」から、画面中央に点を表示できます。

エイムする際の参考に使えたり、移動の際にも目印になるので有効にすることをおすすめします。

## 仕様編

### Debug Load

特定の場面下で Alt + V キーを押すと、最新のセーブデータをロードすることができます。以下のような場面で実行できます。

- メニューの開閉時
- セーブ中、ロード中
- エリアに入った時の読み込み
- 武器や特性強化などのUIメニュー中

バグ技の操作手順にも含まれるため、バグありRTAでは必須の操作です。バグなしではごく一部のケースで使われることがあります。

ただし、旗での強化メニュー中に Debug Load を行うと、それ以降のオートセーブが効かなくなるような事象があります。基本的にはRTA中は規定のタイミングでやるようにしましょう。

### 言語差

テキスト自体による差は（おそらく）ありません。

メニューに一部差があり、英語でのプレイでほぼ統一されています。デフォルトのソートが五十音順・アルファベット順のものがあり、メニュー操作に違いが起きます。

公開されているガイドは英語でのプレイが前提となっているので、言語を変える場合はメニュー操作を組みなおしましょう。

### 隊列について

メニュー画面上は隊列に出ているかどうかの違いしか表現されていませんが、内部的には配置順の概念があります。

パーティに加入した順で管理されており、その順序が戦闘中のターン内行動順になります。

RTAのチャート上、メンバーを外す→加えるといった操作がある場合は、この隊列を操作していると考えましょう。

## メニュー操作編

### 初期カーソル位置

武器やスキル・特性の強化メニューも含めて、初期のキャラクターカーソル位置がゲーム進行によって変わります。

基本的な考え方は加入順で、パーティにいる中で最も早いキャラクターが初期カーソルにあたります。メニュー上の順序は関係ありません。

※例: シエル合流時点 - `[ギュスターヴ][ルネ][マエル][シエル]` = 初期カーソル位置はギュスターヴ

ただし例外があり、ACT1終了（ギュスターヴ離脱）後からモノコ加入までにデータのロードを行っていない場合、ギュスターヴの枠にモノコが入る形でモノコが初期カーソルになります。

※ `[モノコ][ルネ][マエル][シエル][ヴェルソ]` になる

### ムービー中メニューのリカバリ

ムービー中にメニューを開く Cutscene Menu ですが、ムービーに入ってしまうと基本的に操作は効かなくなります。

ただし、マウスでの操作は可能なので、マウスで可能な範囲の操作はリカバリができます。

また、ムービースキップ時のポーズは LRT が停止するので、若干ハック寄りですが、ポーズ→マウスを動かす→ポーズ解除→クリック→... とすると最小限のロスでリカバリができます。

## 戦闘編

### スキル選択の簡易入力

- スキル（左中）: `X(□)` 連打
- スキル（左下）: `[E]キー` 連打
- グラディエントスキル1 : `[Q]キー` 連打
